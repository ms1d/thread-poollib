# Benchmark: box-muller

## Overview

Manipulates 2 vectors similar to `vector-add` but via the Box-Muller transformation.
Inspired by [the NAS Parallel Benchmarks (section 2.2.1)](https://www.nas.nasa.gov/assets/nas/pdf/techreports/1994/rnr-94-007.pdf).
I do not claim to have implemented the exact kernel but rather a heuristic that
will nonetheless be more compute-demanding than `vector-add`
